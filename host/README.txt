DSH Remoto 主机包（Windows）0.4.0

适配手机客户端：DSH-remoto-0.4.0.apk
内含：宿主插件 @dsh-remote/plugin 0.5.3、局域网中继 0.5.1、安装与切换脚本

====================================================================
一、这个包做什么
====================================================================
把一台 Windows 电脑变成 DSH Remote 的主机：电脑上跑着的 DeepSeek Harness（DSH）
接受手机下发的指令，把流式输出、工具调用、审批和提问发回手机。

有两种连法，手机里都支持：

  1) 中继模式：电脑和手机都连你自己部署的公网中继（见文末「自建中继服务器」）
     适合不在同一个 Wi-Fi、或者需要在外面用手机看电脑。

  2) 局域网模式：电脑本机跑一个中继，监听 8787 端口。
     手机和电脑连同一个 Wi-Fi，直接连电脑的局域网 IP。
     不经过公网，速度最快；需要放行 Windows 防火墙。

一个主机包只装一台电脑。每台电脑第一次连接时会领取自己的 host token
（中继模式下自动领取），不要把这个 token 发给别人。

====================================================================
二、包里的文件
====================================================================
  run-install.bat        第一次安装（会备份旧插件和配置）
  run-update.bat         只更新插件，保留已有配对与地址
  switch-mode.bat        桌面「连接模式」窗口：一键切换中继/局域网并重启 DSH
  switch-ui.ps1          上面那个窗口的本体
  switch-to-relay.bat    切到中继模式（命令行版）
  switch-to-lan.bat      切到局域网模式（命令行版，自动启动本机中继）
  status.bat             查看当前模式、中继健康、局域网 IP、已配对数量
  run-selftest.bat       不启动 DSH 也能验证：中继、token、配对码链路
  rollback.bat           回滚到最近一次安装前的插件与配置

  relay.txt              中继地址（0.4.0 起默认空白；在「连接模式」里点「配置中继地址」填写）
  token.txt              主机 token；留空表示中继模式自动领取
  relay.mjs              局域网中继（0.5.1）
  plugin\                宿主插件 0.5.3
  selftest.mjs           自检脚本
  backup-<时间>\         每次安装自动生成的备份

====================================================================
三、安装
====================================================================
前提：电脑已装 DSH，并至少启动过一次（存在 %USERPROFILE%\.dsh\profiles\desktop）。

  1. 完全退出 DSH：右上角关闭不够，托盘图标也要退出。
  2. 解压整个压缩包到一个固定目录（不要只把 bat 拖出来）。
  3. 双击 run-install.bat。
  4. 看到 "Install complete" 后重新打开 DSH。
  5. 看 DSH 底部是否出现「远程控制」胶囊。
  6. 桌面上会出现「DSH Remoto 连接模式」快捷方式，以后切中继/局域网用它。

如果已经装过旧版主机包：
  - 直接运行 run-install.bat 即可；它会备份旧插件，并保留现有的
    user-config.json、hostId、host token 和配对记录。
  - 只想更新插件、不改任何配置：运行 run-update.bat。
  - 可以解压到新目录再安装；局域网 token 会从 user-config.json 恢复，
    token.txt 是空的也没关系，不会重置配对。
  - 不要删除 %USERPROFILE%\.dsh\dsh-remote-control，也不要复制别人的 .dsh。
  - 桌面快捷方式会刷新到新解压目录，旧快捷方式可手动删除。

手机 App 升级：
  - 新 APK 的 versionCode 会递增，直接覆盖安装即可，本地主机/端点/PSK 数据保留。
  - 不要先卸载；卸载会清空 App 本地数据。确实要卸载时，先去 App「设置 →
    导出连接配置」备份 JSON，装好后「导入连接配置」。

如果 Windows 提示“已保护你的电脑”：
  点「更多信息」→「仍要运行」。脚本只修改 DSH 的 profile 目录和
  %USERPROFILE%\.dsh\dsh-remote-control，不会安装系统服务。

====================================================================
四、连接方式
====================================================================
最方便：双击桌面上的「DSH Remoto 连接模式」快捷方式。
窗口里能看到当前模式、中继地址、局域网 IP、插件版本、中继状态和已配对数量；
点「中继模式」或「局域网模式」会确认后自动切换并重启 DSH，不需要再手动跑脚本。

【中继模式】（默认）

  1. 双击 switch-to-relay.bat，或用桌面窗口点「中继模式」。
  2. 脚本把中继地址设为 relay.txt 里的地址，并清除旧 token，
     让插件在第一次连接时自动向中继领取新 token。
  3. 按提示完全退出并重新打开 DSH。
  4. 用 status.bat 看 relay state 是否为 online。

  注意：从旧的私有中继切到官方中继时，旧配对会失效，手机需要重新配对。
  这是正常的：token 和通道都属于某一个中继。

【局域网模式】

  1. 手机和电脑连同一个 Wi-Fi（不要用访客网络，访客网络通常隔离设备）。
  2. 双击 switch-to-lan.bat，或用桌面窗口点「局域网模式」。
     - 第一次会自动生成 token.txt；
     - 启动本机中继，监听 0.0.0.0:8787；
     - 打印形如 ws://192.168.1.8:8787 的地址。
  3. 按提示完全退出并重新打开 DSH。
  4. 如果 Windows 防火墙弹窗：勾选“专用网络”，允许 node.exe。
     没有弹窗但手机连不上时，用管理员身份运行：
       powershell -ExecutionPolicy Bypass -File mode.ps1 -Mode lan -OpenFirewall
     或者手动放行 TCP 8787。
  5. 手机 App → 主机 → 编辑局域网地址，填电脑 IP（默认端口 8787），
     保存后点「使用」，再输入电脑上刷新出来的 6 位码配对。

  局域网中继只在电脑上运行；电脑休眠或退出 DSH 后手机就连不上。
  想关掉本机中继：把电脑切回中继模式即可（switch-to-relay.bat 会停止它）。

====================================================================
五、手机端配对
====================================================================
  1. 电脑 DSH 底部点「远程控制」胶囊 →「刷新」，屏幕显示 6 位数字。
  2. 手机 App 打开「主机」页，确认当前端点（中继或局域网）已填好地址。
  3. 点该端点下的「配对」，输入 6 位码。
  4. 手机会显示一串 6 位「核对数字」。
     必须和电脑屏幕上显示的 6 位数字逐位一致，再点「数字一致，继续」。
     不一致就点取消——这说明链路可能被替换，不要继续。
  5. 配对成功后进入会话列表。

配对码默认约 2-3 分钟过期；过期回电脑点「刷新」重新生成。
每台主机、每个端点各有一把自己的 PSK；中继和局域网是两套独立配对。

====================================================================
六、自检（不启动 DSH）
====================================================================
双击 run-selftest.bat，或在本目录运行：

  node selftest.mjs

它会读取当前配置（user-config.json / relay.txt），必要时自动领取 token，
然后完成：中继健康检查 → 主机 hello → 发布配对码 → pair-ready。

看到 "PASS" 说明中继地址、token 和配对链路都正常；如果失败，
按输出里的 HTTP 状态 / 错误码排查（bad_token 表示 token 不属于这个中继）。

也可以指定地址和 token 单独测试：

  node selftest.mjs --relay wss://你的中继服务器/v05
  node selftest.mjs --relay ws://192.168.1.8:8787 --token <token.txt 内容>

====================================================================
七、排错
====================================================================
[胶囊不出现]
  - 确认完全重启过 DSH（HMR 不会重新加载插件）。
  - 看 %USERPROFILE%\.dsh\dsh-remote-control\status.json 里的 problems。
  - 如果 DSH 启动崩溃：在崩溃窗口选「Disable third-party plugins…」，
    或把 profile 里的 cordis.patch.yml 改名为 .bak 后重启，再运行 rollback.bat。

[status.bat 显示 relay state 不是 online]
  - 中继模式：先跑 run-selftest.bat。若是 bad_token，说明 token 属于旧中继，
    运行 switch-to-relay.bat 清 token 后重启 DSH，让插件重新领取。
  - 检查 relay.txt 的地址是否可访问；自建中继要同时改 relay.txt 和 token.txt。
  - 公司网络 / 代理可能拦截 wss，换手机热点试一次。

[手机连不上中继]
  - 手机能上外网吗？wss 端口被运营商或公司网络拦截时改用局域网模式。
  - 手机时间要准确（证书校验）。

[局域网连不上]
  - 电脑和手机是否同一个 Wi-Fi；路由器是否开了“AP 隔离/访客网络”。
  - status.bat 是否显示 local relay listening。
  - 防火墙是否放行 node.exe / TCP 8787。
  - 手机里地址要填电脑的局域网 IP，不是 127.0.0.1。

[配对码无效]
  - 码已过期、已被用过，或上面显示的是另一张码；回电脑点「刷新」。
  - 中继和局域网的码不能混用，先确认手机当前端点与电脑当前模式一致。

[手机显示“配对已失效”]
  - 中继重启或电脑换了 relay/token。回电脑刷新配对码，手机重新配对。

====================================================================
八、备份与回滚
====================================================================
每次 run-install.bat 都会在包目录生成 backup-<时间>：
  plugin\           安装前的插件
  package.json      安装前的 profile 清单
  user-config.json  安装前的用户配置（如果存在）

回滚：完全退出 DSH，双击 rollback.bat。它会恢复最近一次备份。
hostId、host-token.json 和配对记录不会被安装器删除；如果需要彻底重置，
先退出 DSH，再手动备份并删除 %USERPROFILE%\.dsh\dsh-remote-control。

====================================================================
九、安全
====================================================================
  - 内容端到端加密：中继只转发 ciphertext，看不到正文、审批内容或附件。
  - 手机端核对 6 位数字是发现中继替换公钥的唯一手段，不要跳过。
  - 局域网模式使用 ws://（明文传输层），但载荷仍然是端到端加密的；
    只建议在可信的家庭/办公室 Wi-Fi 使用。
  - token.txt、status.json 里的 token 等价于主机凭据，不要发群、不要截图外传。
  - 不要把别人的 .dsh 目录复制过来，否则 hostId 和 token 会冲突。
关于插件覆盖（0.3.9 起）
------------------------
安装器会把补丁插件放在：
  %USERPROFILE%\.dsh\dsh-remote-control\plugin-patched
并把 profile 的依赖改成 link: 指向这个目录，同时在 node_modules 里创建 junction。
这样再安装 dsh-whale-widget、dsh-pet 等其他插件时，pnpm 不会再从 npm 重装官方
@dsh-remote/plugin 覆盖补丁，其他插件也不会被删除。
如果以后 DSH 升级或插件管理器重写了依赖，重新运行 run-update.bat 即可恢复。

自建中继服务器（0.4.0 起不再内置公共中继）
------------------------------------------------
1. 准备一台有公网 IP 的 Linux VPS、一个域名和 Node.js 20。
2. 把本包里的 relay.mjs 上传到 /opt/dsh-remote/relay.mjs。
3. 在服务器上启动：
   DRC_PORT=8787 DRC_BIND=127.0.0.1 DRC_PUBLIC_URL=wss://relay.example.com node /opt/dsh-remote/relay.mjs
4. 用 Caddy 反代（自动 HTTPS）：
   relay.example.com {
     reverse_proxy 127.0.0.1:8787
   }
5. 中继地址就是 wss://relay.example.com/v05，电脑和手机必须填同一个地址。
6. 电脑桌面「连接模式」→「配置中继地址」填入该地址 →「中继模式」。
7. 手机 App → 添加主机 → 连接方式选「中继服务器」→ 填同一地址 → 配对。

给 DSH 的安装/配置指令可以直接从 App 教程里复制。
