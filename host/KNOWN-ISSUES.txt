SSH Remoto 0.3.9 内测说明 / Known issues
========================================

这是一版内测包，适合先在 1-3 台自己的电脑/手机上验证，不建议直接大规模分发。

已在本机验证
------------
- 全新假 profile 安装成功，桌面快捷方式指向新目录；
- 手机扫码（系统相机拍照解码）连接局域网成功；
- 电脑 → 手机图片显示成功；
- 电脑 → 手机文件卡与「保存到手机」；
- 审批卡、电脑权限、白色 UI；
- 覆盖安装保留本地主机/端点/PSK。

已知限制
--------
1. 宿主插件是 @dsh-remote/plugin 0.5.3 + 本项目的图片/文件/权限补丁，
   不是官方新版本。SSH 升级后如果覆盖了插件，需要重新运行 run-install.bat。
2. 电脑 → 手机图片/文件：
   - 单个文件上限 512KB；
   - 目前只保证在线实时显示，重进会话后的持久历史缓存尚未实现；
   - 文件保存到手机下载目录（Android 10+）；旧 Android 保存在 App 的下载目录。
3. 二维码扫码：
   - 点「扫码」打开系统相机，拍下电脑屏幕二维码后解码，不是实时取景；
   - 二维码只自动填地址，仍需输入电脑上的 6 位配对码并核对 SAS；
   - 二维码临时文件在 %TEMP%，关闭连接模式窗口或 2 分钟后自动删除。
4. 修改权限预设后需要 SSH 重启一次才能加载新命令；当前会话权限以电脑端显示为准。
5. App 使用自签测试证书（CN=SSH Remoto Test），不是应用商店签名。
6. 新电脑如果 SSH 不在默认路径，桌面窗口的「打开 SSH」可能找不到程序；
   请手动启动 SSH，模式切换脚本会优先使用正在运行的 SSH 路径。
7. 防火墙需要允许 TCP 8787；访客 Wi-Fi/AP 隔离会导致扫码后连不上。

给测试者的建议
--------------
- 先测局域网：同一 Wi-Fi → 桌面「局域网模式」→ 显示二维码 → 手机扫码 → 6 位码 → SAS。
- 再测中继：桌面「中继模式」→ 手填 wss://你的中继服务器/v05 → 重新配对。
- 测图片/文件时让电脑保持空闲；文件先试小文本，再试 APK/图片。
- 出问题请记录：手机型号/Android 版本、App 版本、电脑 SSH 版本、
  当时是局域网还是中继、截图和大概时间。
关于插件覆盖（0.3.9 起）
------------------------
安装器会把补丁插件放在：
  %USERPROFILE%\.dsh\dsh-remote-control\plugin-patched
并把 profile 的依赖改成 link: 指向这个目录，同时在 node_modules 里创建 junction。
这样再安装 dsh-whale-widget、dsh-pet 等其他插件时，pnpm 不会再从 npm 重装官方
@dsh-remote/plugin 覆盖补丁，其他插件也不会被删除。
如果以后 SSH 升级或插件管理器重写了依赖，重新运行 run-update.bat 即可恢复。

自建中继服务器（0.4.0 起不再内置公共中继）
------------------------------------------------
1. 准备一台有公网 IP 的 Linux VPS、一个域名和 Node.js 20。
2. 把本包里的 relay.mjs 上传到 /opt/dsh-remote/relay.mjs。
3. 在服务器上启动：
   DRC_PORT=8787 DRC_BIND=127.0.0.1 DRC_PUBLIC_URL=wss://relay.example.com node /opt/dsh-remote/relay.mjs
4. 用 Caddy 反代（自动 HTTPS）：
   relay.example.com {
     reverse_proxy 127.0.0.1:8787
   }
5. 中继地址就是 wss://relay.example.com/v05，电脑和手机必须填同一个地址。
6. 电脑桌面「连接模式」→「配置中继地址」填入该地址 →「中继模式」。
7. 手机 App → 添加主机 → 连接方式选「中继服务器」→ 填同一地址 → 配对。

给 DSH 的安装/配置指令可以直接从 App 教程里复制。
